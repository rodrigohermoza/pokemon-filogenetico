# Árbol filogenético de Pokémon

¿Qué pasaría si los Pokémon fueran seres vivos reales y les aplicáramos las mismas herramientas que usa un biólogo para reconstruir el árbol de la vida?

Este proyecto convierte los rasgos de cada Pokémon (tipos, grupos huevo, forma del cuerpo, hábitat, color, estadísticas…) en una **matriz de caracteres**, el mismo tipo de dato que se usa en filogenética morfológica con fósiles, y reconstruye su árbol evolutivo con software real de filogenética.

**Estado:** ideación. Ver [docs/00-retomar.md](docs/00-retomar.md).

Inspirado en el video de The31st, [I Spent 5+ Years Building a DNA-based Pokémon Evolutionary Tree of Life](https://youtu.be/2DUg-AXaX7w).

Documentación completa en [docs/](docs/README.md).
