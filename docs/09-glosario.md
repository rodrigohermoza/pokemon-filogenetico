# Glosario (con ejemplos Pokémon)

| Término | Qué es | Ejemplo |
|---|---|---|
| Carácter | Rasgo que puede variar entre organismos | "Pertenece al grupo huevo Dragón" |
| Estado | Valor que toma un carácter | sí / no; o forma = cuadrúpedo |
| Matriz de caracteres | Tabla organismos × caracteres; el "alineamiento" de la morfología | 151 filas × ~60 columnas |
| Clado | Un ancestro y **todos** sus descendientes | Charmander + Charmeleon + Charizard |
| Monofilético | Grupo que forma un clado | Lo esperado para cada línea evolutiva |
| Homoplasia | Mismo estado surgido de forma independiente (convergencia) | Tipo fuego en Charmander y en Ponyta |
| Grupo externo | Organismo fuera del grupo de interés usado para enraizar | ¿Mew? |
| Bootstrap | Remuestrear columnas de la matriz y repetir para medir el soporte de cada rama | Rama con 95 = muy estable |
| Modelo Mk | Modelo de verosimilitud para caracteres morfológicos con k estados (Lewis 2001) | Usado en IQ-TREE con `-st MORPH` |
| Neighbor-Joining | Construye el árbol uniendo los pares más cercanos según una matriz de distancias | Prototipo rápido |
| Parsimonia | Elige el árbol que requiere menos cambios de estado | Método clásico con fósiles |
| Robinson-Foulds | Distancia entre dos árboles: cuántas particiones difieren | Comparar NJ vs IQ-TREE |
